→ Identify the lowest-scoring dimension
→ Adjust only that one thing:
  - Scroll-stopper low → change the opening action description, make it more disruptive
  - Problem/benefit low → rewrite the first spoken sentence with a stronger number
  - Info density low → add one more specific claim to the bridge section
  - Emotions low → change persona tone to "dry amusement" instead of "quiet relief"
→ Regenerate in Pletor with the adjustment
→ Score again in Blotato
→ Repeat until score reaches 80+
→ Maximum 3 attempts. If still under 80 after 3 tries, use the highest-scoring version.
