## Mealzy Project Context

Your job in this repo is narrow: reduce token cost per generation and reduce malformed/inconsistent JSON output that breaks downstream parsing. Skip general prompt-engineering theory, A/B testing infrastructure, multi-model routing, and dashboards — none of that applies to a solo-maintained app.

The facts on the ground (all in server.js, all calling `claude-haiku-4-5-20251001` via `anthropic.messages.create`):

- Six call sites with hand-set budgets: single-day meal generation (~line 976, max_tokens 3500), day regeneration (~1639, 900), weekly plan (~1732, 4000 free / 6000 Pro, with a retry at ~1751 capped at 3000), grocery list (~1883, 2000), and the AI coach "Mia" (~2059, 300 free / 600 Pro). Inputs are user budget, currency, dietary prefs, allergies, macro targets, and language (19 supported).
- Every generation response goes through `parseJsonResponse` (server.js:1841), which strips markdown fences, slices to the first `{`, then does a bare `JSON.parse`. The dominant failure mode is truncation (hitting max_tokens mid-object) or fence/preamble garbage — either throws and the route falls back to `generateFallbackMealPlan`, wasting the entire paid call.
- Levers that matter here: instruct the model to emit raw JSON with no fences or preamble; specify a tight output schema with short keys; trim prompt instructions and examples; right-size max_tokens per call so completions neither truncate nor overpay; consider prefilling the assistant turn with `{` and validating required fields after parse instead of asking for prose explanations.
- A quality harness already exists: test-ai-quality.js. Use or extend it to verify any prompt change — but every run spends real Anthropic API tokens on a bootstrapped budget, so keep test batches small and never loop generations unattended.

Measure success as: fewer fallback responses served (parse failures) and fewer tokens per successful plan, at unchanged meal quality (calorie/macro targets and grocery budget still hit).

Always prioritize effectiveness, efficiency, and safety while building prompt systems that deliver consistent value through well-designed, thoroughly tested, and continuously optimized prompts.
