## SPEC: Annual Stripe Plan ($62/year)

Since this is the highest-priority unspecced feature (ICE 9), writing this spec now.

```
FEATURE: Annual Stripe Plan ($62/year)
Date: 2026-05-28

PROBLEM:
Monthly subscribers churn at high rates because there's no commitment friction. Industry data shows annual subscribers churn ~70% less than monthly. We currently offer only $8/mo — users who would commit long-term have no option to do so, and we leave money on the table. Every month, users re-evaluate whether to cancel. Annual billing removes 11 of those decision points.

USER STORY:
As a user who likes Mealzy and wants to commit long-term, I want to pay annually at a discount, so that I save money and don't have to think about my subscription every month.

SUCCESS METRIC:
- Primary: 20% of new Pro signups choose annual within 6 weeks of launch
- Secondary: Annual subscribers retain at 80%+ after 6 months (vs current monthly baseline — need Riley to establish)

SCOPE (what's in):
- New Stripe Price object: $62/year for Pro (save ~35% vs monthly)
- Update /upgrade.html to show both options (monthly default, annual highlighted as "Best Value")
- Update Stripe webhook handler to recognize annual subscription interval
- Update user record to store billing_interval ('monthly' | 'annual')
- Update /account.html to display correct billing interval and renewal date
- Update cancel flow to show annual-specific messaging ("You have X months remaining")

OUT OF SCOPE (what's not in):
- Family annual plan (separate feature, different price point)
- Migration path for existing monthly subscribers to switch to annual (v2 feature)
- Proration or partial refunds for mid-cycle changes
- Annual-specific onboarding or welcome flow
- Annual-exclusive features (annual and monthly Pro get identical features)

ACCEPTANCE CRITERIA:
- [ ] Stripe has a new Price object: $62/year, linked to Pro product
- [ ] /upgrade.html displays both monthly ($8/mo) and annual ($62/yr) options
- [ ] Annual option is visually marked as "Best Value" or "Save 35%"
- [ ] Clicking annual option initiates Stripe Checkout for annual price
- [ ] Successful annual checkout creates user with plan='pro' and billing_interval='annual'
- [ ] Webhook correctly processes annual subscription events (created, renewed, cancelled)
- [ ] /account.html shows "Pro (Annual)" and next renewal date for annual subscribers
- [ ] Cancel flow for annual users shows remaining time ("Your access continues until [date]")
- [ ] Free users see annual option on upgrade page
- [ ] No errors when annual subscription renews (test in Stripe test mode)

EDGE CASES:
- What if the user is on free tier? → They see both monthly and annual options on upgrade page
- What if the user is already monthly Pro? → v1: they cannot switch. v2 will add upgrade path. For now, they see their current plan on /account.html with no annual upsell.
- What if Stripe is down? → Same error handling as monthly — show user-friendly error, log to console, retry guidance
- What if the user has no plan yet? → Same as free tier — offer both options at signup/upgrade
- What if annual user cancels mid-year? → Access continues until period end. Stripe handles this automatically. Messaging: "Your Pro access continues until [date]. You won't be charged again."
- What if webhook fails to process annual renewal? → Log error, alert Morgan. User record should auto-update on next API call to Stripe.

TRACKING (for Riley):
- Event: `upgrade_page_viewed` — include property: `options_shown: ['monthly', 'annual']`
- Event: `plan_selected` — include property: `plan_type: 'annual' | 'monthly'`
- Event: `checkout_completed` — include property: `billing_interval: 'annual' | 'monthly'`
- Event: `subscription_cancelled` — include property: `billing_interval: 'annual' | 'monthly'`

WHO NEEDS TO KNOW:
- Morgan: Build the Stripe Price, update upgrade.html, update webhooks, update user schema for billing_interval, update account page and cancel flow
- Quinn: No AI changes required
- Riley: Set up tracking for annual vs monthly selection (events above). We need to measure annual adoption rate and compare retention.
- Casey: Confirm $62/yr price point (35% discount). Ensure upgrade page copy positions annual as "Best Value" without making monthly feel like a bad choice.
```
