## MEMORY UPDATE

- **"Dead by Wednesday" is a strong Slide 1 anchor.** Named day + implied failure (not stated failure) creates an immediate mirror effect. The word "dead" is not banned and functions as a tension word without being shock-caps. Keep this pattern for frustration-relief hooks.
- **CTA split confirmed in production.** Variant A uses save-CTA ("Save this if meal planning never sticks") and Variant B uses follow-CTA ("Follow for one meal planning tip every day"). Pull 48h data for both — saves on A, follower gain on B — and log which format wins before next Thursday.
- **"$23 decision" framing is the strongest financial hook tested so far.** Attaching a specific dollar amount to a physical behaviour (opening the fridge) is more visceral than attaching it to a monthly total. Test "$23 decision" headline format again in a future money-pillar carousel.
- **No Windsor.ai data available yet.** This is the second Thursday with no returnable performance data. First real baseline will come from these two carousels posting. Set expectation: next Thursday's performance review should have live saves/reach/shares numbers for at least one carousel.
- **"Planning gap not willpower problem" is the save-worthy Slide 8 reframe.** This reframe does emotional work — it removes shame and replaces it with a solvable problem. Reframes that move blame from the person to the system consistently earn saves. Apply this structure to future aha-moment slides: [thing viewer blames themselves for] is not [character flaw]. It's [system problem].
