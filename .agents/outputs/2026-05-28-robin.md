### Exit Survey Spec (P1)
**Trigger:** When a Pro user clicks "Cancel subscription" in account settings
**Display:** Modal appears BEFORE cancellation completes
**Questions:**

```
Question 1 (required, single-select):
Label: "We're sorry to see you go. What's the main reason you're cancelling?"

Options:
- Too expensive for what I get
- Didn't use it enough
- Meal plans didn't fit my diet/preferences
- Missing a feature I need
- Found a different solution
- Just trying it out — might come back
- Other

If "Other" selected: show text field (max 200 chars)

Question 2 (optional, open text):
Label: "Is there anything we could have done to keep you?"
Placeholder: "Your feedback helps us improve..."
Max: 500 chars
```

**Data storage:** New table `exit_surveys` with columns:
- `id` (primary key)
- `user_id` (foreign key)
- `reason` (enum matching options above)
- `other_reason_text` (nullable)
- `improvement_feedback` (nullable)
- `subscription_duration_days` (calculated from subscribe date)
- `created_at`

**Why this matters:** Mealzy currently has zero visibility into why users churn. Every week without this survey is a week of flying blind.

---

### NPS Modal Spec (P2)
**Trigger:** Pro user, 14 days after subscription start, has generated at least 2 plans
**Frequency:** Once per user (don't re-show)
**Display:** Non-blocking modal, dismissable

```
Screen 1:
Label: "Quick question — how likely are you to recommend Mealzy to a friend?"
Scale: 0-10 (horizontal buttons, 0 labeled "Not likely", 10 labeled "Extremely likely")

Screen 2 (conditional):
If score 0-6 (Detractor):
  Label: "What's the main thing we should improve?"
  Open text, max 300 chars

If score 9-10 (Promoter):
  Label: "What do you love most about Mealzy?"
  Open text, max 300 chars

If score 7-8 (Passive):
  Label: "Thanks for your feedback!"
  (no follow-up question)
```

**Data storage:** New table `nps_responses` with columns:
- `id`
- `user_id`
- `score` (0-10)
- `follow_up_response` (nullable)
- `created_at`
